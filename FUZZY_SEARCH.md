# Нечіткий пошук (Fuzzy Search) в KATOTTG Tree

## Що таке Fuzzy Search?

Нечіткий пошук (fuzzy search) - це технологія пошуку, яка дозволяє знаходити результати навіть при:
- Помилках в написанні
- Неповних збігах
- Відмінностях в регістрі
- Пошуку по окремих словах

## Як увімкнути?

1. Відкрийте **KATOTTG Settings**
2. Знайдіть секцію "Налаштування пошуку"
3. Встановіть галочку **"Увімкнути нечіткий пошук"**
4. Збережіть налаштування

## Як це працює?

Fuzzy search використовує **багаторівневу стратегію пошуку** з різними рівнями точності:

### Рівень 1: Точний збіг (Relevance: 100%)
Шукає повний точний збіг по коду або назві.

**Приклад:**
```
Запит: "Запоріжжя"
Знайде: точно "Запоріжжя"
```

### Рівень 2: Збіг на початку (Relevance: 80%)
Шукає об'єкти, що починаються з вашого запиту.

**Приклад:**
```
Запит: "Запор"
Знайде: "Запоріжжя", "Запорізька область"
```

### Рівень 3: Збіг будь-де (Relevance: 60%)
Шукає об'єкти, що містять ваш запит в будь-якому місці.

**Приклад:**
```
Запит: "зька"
Знайде: "Запорізька область", "Київська область"
```

### Рівень 4: Пошук по словах (Relevance: 40-60%)
Шукає по окремих словах з вашого запиту.

**Приклад:**
```
Запит: "Запорізька громада"
Знайде об'єкти що містять:
- "Запорізька" АБО "громада"
- Чим більше слів збігається, тим вища релевантність
```

## Відмінності від звичайного пошуку

### Звичайний пошук (Enable Fuzzy Search = OFF):
- Простий пошук по LIKE %query%
- Швидкий, але менш гнучкий
- Результати сортуються по коду

### Fuzzy Search (Enable Fuzzy Search = ON):
- Багаторівневий пошук з різними стратегіями
- Повільніший, але знаходить більше результатів
- Результати сортуються по **релевантності**
- Кожен результат має поле `relevance` (0-100)

## Приклади використання

### JavaScript (Frontend):
```javascript
// Пошук з fuzzy search
frappe.call({
    method: "katottg_tree.utils.api.search_katottg",
    args: {
        query: "Мелітоп",  // Неповний запит
        limit: 20
    },
    callback: function(r) {
        console.log(r.message);
        // Результати відсортовані по релевантності
        // Знайде "Мелітополь" навіть при неповному написанні
    }
});
```

### Python (Backend):
```python
from katottg_tree.utils.api import search_katottg

# Пошук об'єктів
results = search_katottg(
    query="Запоріж",
    filters={"category": "M"},  # Тільки міста
    limit=10
)

for result in results:
    print(f"{result['title']} (relevance: {result.get('relevance', 0)}%)")
    print(f"Full path: {result['full_path']}")
```

## Оптимізація продуктивності

Fuzzy search може бути повільним на великих обсягах даних. Рекомендації:

1. **Обмежте кількість результатів:**
   - За замовчуванням: 50 результатів
   - Налаштовується в KATOTTG Settings > "Максимальна кількість результатів пошуку"

2. **Використовуйте додаткові фільтри:**
   ```python
   search_katottg(
       query="громада",
       filters={"category": "H"},  # Тільки громади
       limit=20
   )
   ```

3. **Використовуйте кешування:**
   - Результати пошуку не кешуються, але `full_path` кешується
   - Це прискорює формування результатів

## Налаштування релевантності

Оцінки релевантності (в файлі api.py):

```python
# Рівень 1: Точний збіг
r["relevance"] = 100

# Рівень 2: Починається з
r["relevance"] = 80

# Рівень 3: Містить
r["relevance"] = 60

# Рівень 4: Пошук по словах
r["relevance"] = 40 + (matched_words * 5)
```

Ви можете змінити ці значення в функції `_fuzzy_search()` в файлі `api.py`.

## Коли використовувати?

### Використовуйте Fuzzy Search якщо:
- ✅ Користувачі часто роблять помилки в написанні
- ✅ Потрібен пошук по частинах назв
- ✅ Потрібен інтелектуальний пошук
- ✅ Важливіша релевантність, ніж швидкість

### Використовуйте звичайний пошук якщо:
- ✅ Потрібна максимальна швидкість
- ✅ Користувачі знають точні назви
- ✅ Важливе простое сортування по коду
- ✅ Великий обсяг даних (100,000+ записів)

## Приклади роботи

### Приклад 1: Пошук міста з помилкою
```
Запит: "Мелитопол"  (з помилкою)
Fuzzy Search знайде: "Мелітополь" (релевантність: 80%)
```

### Приклад 2: Пошук по частині назви
```
Запит: "Запор"
Fuzzy Search знайде:
1. "Запоріжжя" (80%)
2. "Запорізька область" (80%)
3. "Запорізький район" (80%)
```

### Приклад 3: Пошук по кількох словах
```
Запит: "Запорізька міська"
Fuzzy Search знайде:
1. "Запорізька міська громада" (50% - 2 слова)
2. "Запорізька область" (45% - 1 слово)
3. Інші об'єкти з "міська" або "Запорізька"
```

## Технічні деталі

### Структура результату:
```json
{
    "name": "UA23080070010092407",
    "code": "UA23080070010092407",
    "title": "Мелітополь",
    "category": "M",
    "parent_katottg": "UA23080070010000000",
    "is_group": 1,
    "relevance": 100,
    "full_path": "Запорізька область, Мелітопольський район, Мелітопольська ТГ, м. Мелітополь"
}
```

### Алгоритм роботи:
1. Перевірка налаштувань (`enable_fuzzy_search`)
2. Якщо увімкнено - викликає `_fuzzy_search()`
3. Виконує 4 рівні пошуку послідовно
4. Збирає унікальні результати
5. Сортує по релевантності
6. Додає `full_path` для кожного результату
7. Обмежує до заданого ліміту

## Подальші покращення

Можливі майбутні доповнення:

1. **Levenshtein Distance** - обчислення відстані редагування
2. **Soundex/Metaphone** - фонетичний пошук
3. **N-gram matching** - пошук по підрядках
4. **ML-based ranking** - машинне навчання для релевантності
5. **Транслітерація** - підтримка латинки для української
